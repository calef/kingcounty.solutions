title: Now Available! NCBI Hidden Markov Models (HMM) Release 19.0
topic_titles: []
---

Release 19.0 of the NCBI protein profile Hidden Markov models (HMMs) is now available for download. This update features 18,513 HMMs, including 465 new models since the previous release (18.0). Users can utilize the HMMER sequence analysis package to search this collection against prokaryotic proteins to identify their functions. The Protein Family Model collection includes details about these models, conserved domain architectures, and BlastRules, along with access to all RefSeq proteins associated with them.

Looking ahead, to conserve space on FTP, older data directories will be modified starting with release 20.0. However, the complete data for the last five releases will still be available. Modifications will involve removing individual HMM and SEED directories, as the data will remain accessible within their corresponding HMM and SEED tarball files. Feedback and questions from users are encouraged.
